F8: review cycles (at most 2)
Goal: an independent, complete, real-size score. Manifest: every screen and state, light and dark, at 960x640, 1280x800, 1920x1080 and 2560x1440 (no 900x600). Motion evidence: for the Live sweep and the Replay, 12 evenly spaced frames per sweep as one strip per theme, plus a 6x-throttled strip, using the new pen. Build the pack with `cd app && bash ../.ui-overhaul/measure/make_pack.sh <N>` (update it for the new sizes; do not weaken it), put it in `.ui-overhaul/review3/cycle<N>/`, and include the pen performance JSON. Reviewers: two fresh-context reviewers (separate agents or new sessions) per cycle. Each receives only the rubric, the manifest and the images, not your reasoning or earlier scores. Each must list every file it opened; a review that skipped files is invalid and is rerun. Each scores every rubric line 0 to 5 with written evidence and names the three weakest points. They first try to break the latest fixes. Rubric lines: Distinctiveness (not mistaken for another product, none of the generic defaults); Subject fit; Hierarchy and focus (one primary action per view); Typography; Color and contrast; Purposeful motion (from the strips and frame data); Craft (alignment, rhythm, density); Usability (steps and time per main job no worse than baseline); Signature moment (the pen); Consistency. Rules: after cycle 1, turn each finding with evidence into a task, fix, run gates, rebuild the pack, then run cycle 2. Stop after cycle 2. Record both reviewers' scores, the mean, and the difference between reviewers. Report scores honestly; do not rerun a review to get a better number. Acceptance: DONE only if both reviewers in the same cycle have every line at 4 or more and a mean of 4.3 or more; otherwise ESCALATED.
