G4: the rail mini sheet draws the live trace
Goal: the rail shows a small drawn trace instead of text while a run is active. Not doing: a pen in the rail; any new data source. Limits: reads only the readings the UI already receives; draws only new segments each update (never redraws the whole trace except on resize or theme change); sleeps when hidden, off screen or not running; at most 160 by 48 px; device pixel ratio capped at 2; no blur or filter. Work: a small canvas with a faint grid, ink in the accent colour, an end dot at the latest reading, and an accessible name ("Live memory trace, latest reading N MB"). When no run is active, show the last trace or a quiet empty state. Reduced motion: no smooth animation; the trace updates once per reading. Acceptance checks:

* New e2e: during a run the rail canvas exists, has a non-blank drawing after 3 readings, and has an accessible name containing the latest value; when hidden (`document.hidden`) no frame loop runs (verified by a counter exposed only in dev builds, or a rAF spy).
* `pnpm perf` for the pen: script share not above 2.0 % (1x) and 2.5 % (6x) with the rail trace active; idle CPU not above 0.05 %.
* Gates exit 0; axe zero violations. Done when: checks pass, light and dark screenshots in `.ui-overhaul/review4/g4/`, one commit.
