G7: measurement, one full-size review, report, tag

1. Fresh base: build the starting commit from `.ui-overhaul/base-ref` in a temporary git worktree, build both with the same method, run the startup proxy (at least 20 runs each, same session) and compare bundle sizes; remove the worktree afterwards with `git worktree remove <path>` (one path at a time) and `git worktree prune`. If the base cannot be built, record NOT RUN with the reason.
2. Reduced motion: an e2e that, with `reducedMotion: "reduce"`, checks every pen surface (Run sheet, rail trace, Replay) does not autoplay, and that pressing Replay or Play still plays. Forced-colors check on every screen.
3. Review pack at real size: for each screen and state, light and dark, at 960x640, 1280x800, 1920x1080 and 2560x1440, save one full-size, uncropped screenshot per image (no contact sheets, no downscaling below 100 %), plus the motion strips (12 evenly spaced frames per sweep, per theme, and a 6x-throttled strip) and the pen performance JSONs. Put them in `.ui-overhaul/review4/cycle1/` with a manifest.
4. Review: two fresh-context reviewers (separate agents or new sessions). Each receives only the rubric, the manifest and the images, not your reasoning or earlier scores. Each must list every file it opened; a review that skipped files is invalid and is rerun. Each scores every rubric line 0 to 5 with written evidence, and writes two lists: "blocking at real size" (defects verifiable in a full-size image, each with the file and the pixel region) and "taste notes" (opinions). Rubric lines: Distinctiveness, Subject fit, Hierarchy and focus, Typography, Color and contrast, Purposeful motion, Craft, Usability, Signature moment, Consistency.
5. Fix every item in "blocking at real size" that you can verify yourself, with a failing check first; log any you reject with the reason. Do not rerun a review to get a better number. Report scores honestly, including the spread between reviewers.
6. Final report (section 10 of the brief), the tag `ui-overhaul-4-final`, and a clean tree apart from the owner's items.
